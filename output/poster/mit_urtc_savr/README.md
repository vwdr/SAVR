# SAVR MIT URTC Research Poster

This directory contains the complete LaTeX source for the SAVR research poster.

- Canvas: 24 x 36 inches, portrait
- Compiler: XeLaTeX
- Main wireframe: `savr_urtc_poster_wireframe.tex`
- Content slots: introduction, experimental design, three result families, discussion, limitations, references, acknowledgments, contact information, and repository QR code

Compile twice with:

```text
xelatex savr_urtc_poster_wireframe.tex
xelatex savr_urtc_poster_wireframe.tex
```

The poster is designed for the MIT URTC 24 x 36 inch portrait format. Introduction and Methods appear side by side above a figure-led Results section, followed by Discussion and Conclusion, a separate Limitations panel, and a four-part footer. Red is reserved for the section structure; all wireframe boundaries are black. Final figures should be neutral-first and use red only for a scientifically meaningful highlight.
